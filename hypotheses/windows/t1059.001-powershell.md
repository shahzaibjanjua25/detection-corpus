# Hypothesis: How do we detect malicious encoded PowerShell without drowning in deployment noise?

## Attack chain position
Execution. Frequently used after initial access for payload staging and C2.

## Observable telemetry
process_creation with powershell.exe / pwsh.exe and -EncodedCommand / -e / -enc switches. Script-block logging (Event 4104) provides deeper content if available.

## Success criteria
True positive when encoded PowerShell is launched by an unexpected parent or downloads additional content immediately after.

## Rules generated
- PowerShell Encoded Command Execution
- Encoded PowerShell Followed by Outbound Network (correlation)
