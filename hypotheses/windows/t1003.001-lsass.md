# Hypothesis: Can we reliably detect LSASS memory access for credential dumping?

## Attack chain position
Credential Access stage after initial access and privilege escalation. Often precedes lateral movement.

## Observable telemetry
- process_creation: procdump, rundll32+comsvcs, taskmgr with lsass
- (optional) Sysmon Event 10 (process access) with GrantedAccess 0x1010 or 0x1410 targeting lsass.exe

## Success criteria
True positive when a non-system process opens LSASS with dump permissions or launches a known dumping tool targeting LSASS, outside of approved IR activity.

## Rules generated
- LSASS Memory Dump via Procdump or Similar Tools
- Mimikatz Command Line Indicators
